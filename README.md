# Toma Rani Kabiraj — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Folder structure

- `index.html` — main portfolio page
- `style.css` — design and responsive styles
- `script.js` — mobile navigation and scroll animations
- `images/profile.png` — profile photo

## Run locally

Open `index.html` in a browser.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Before publishing

Add your final CV PDF if you want a Download CV button, and update GitHub/LinkedIn links when you have them.
